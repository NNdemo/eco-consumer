# EcoConsumer App

A mobile-optimized web application that helps users track their carbon footprint, participate in sustainability challenges, and learn more about eco-friendly lifestyle choices.

## Features

- 🌱 **Carbon Footprint Tracking**: Monitor your environmental impact across different categories
- 🏆 **Sustainability Challenges**: Join fun challenges and earn badges for eco-friendly actions
- 📚 **Knowledge Center**: Learn about sustainable living through curated articles
- 👤 **User Profile**: Track your progress and achievements

## Project Setup

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Tech Stack

- **Vue.js 3**: Frontend framework with Composition API
- **Vue Router**: For navigation between pages
- **Font Awesome**: Icons library

## MVP Scope

This application is a Minimum Viable Product (MVP) designed to test key assumptions about how users interact with sustainability tracking tools. The focus is on simplicity and testing user engagement with core features.

## Mobile-First Design

The application is optimized for mobile devices, with a clean and intuitive interface that makes sustainable living more accessible.
